# Storylines

**A. The 45-minute prompt (built).** A moment in someone's day, match cuts on one circle. Claude asks for permission at 14:02, nobody notices until 14:47 because six terminal tabs look alike. The panel gets six dots, one goes red, floods the frame, and the prompt gets answered. Silent, because a README autoplays muted.

**B. Traffic control.** One frame that rebuilds: six dots run a little air traffic board with live state changes, ending on a single red hold. Clever, but a stranger has to learn the metaphor first.

**C. Red.** Type carries the argument: giant kinetic type on red, green and grey floods cut hard, no UI until the last five seconds. The most striking of the three, but it shows the product least.
